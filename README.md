# Chaithra Mahadevaswamy — Portfolio

A responsive portfolio for Chaithra Lokasara Mahadevaswamy, built with plain HTML, CSS, and JavaScript. It has no build step or package dependencies. The content was assembled from all three pages of the supplied résumé and includes project summaries, experience, education, publications, skills, awards, and contact links.

## Preview

Open `index.html` in a browser, or serve this folder with any static file server. The site can be deployed to GitHub Pages, Netlify, Vercel, or any static host.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive styling
- `details.css` — project, publication, and credential sections
- `credentials.css` — certification and language sections
- `education-achievements.css` — education and achievements columns
- `script.js` — small progressive enhancements
- `assets/chaithra-mahadevaswamy.jpg` — supplied portrait

The direct phone and email details and résumé download are intentionally omitted from the public-facing site. The contact form uses Netlify Forms and only works after deploying to Netlify with form detection enabled. Configure a submission email notification in the Netlify dashboard to receive inquiries. See [Netlify Forms setup](https://docs.netlify.com/manage/forms/setup/).
